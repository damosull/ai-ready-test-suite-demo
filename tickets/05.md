# 05 · Order: order staff can leave a note on an order

**Type:** Test coverage · **Area:** Orders / History · **Priority:** Medium

## Context

Customer service staff use the order history to leave notes for each other ("customer called,
wants delivery after 5pm"). Those staff are not admins: they hold only the order-management
permission. There is no e2e coverage of notes, and none of the order specs run as anyone other
than the superuser.

## What to cover

As a staff member whose only permission is managing orders:

1. Open the unpaid order from the orders test data.
2. Add a note to the order history.
3. The note appears in the history.

## Acceptance criteria

- [ ] The test runs as the staff user with only the order-management permission, not the
      superuser.
- [ ] After adding it, the note's text is shown in the order history.
- [ ] The note is still shown after the page is reloaded.

## Notes

- The seed already has a staff user per permission; use the order one.
- Use the existing orders test data.
