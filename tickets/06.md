# 06 · Customers: customer service staff can save a note on a customer

**Type:** Test coverage · **Area:** Customers · **Priority:** Medium

## Context

Customer service keeps short notes on a customer's record ("prefers delivery after 5pm",
"VIP, call before cancelling"). The people who write them hold only the customer-management
permission, not admin. The note is a field on the customer's details page and is saved with the
page's Save button. There is no e2e coverage of the customers area at all.

## What to cover

As a staff member whose only permission is managing customers:

1. Open the customer from the orders test data (Ada Lovelace, `e2e.customer@example.com`).
2. Write a note and save the page.
3. The note is saved on the customer.

## Acceptance criteria

- [ ] The test runs as the staff user with only the customer-management permission, not the
      superuser.
- [ ] After saving, the note field shows the new note.
- [ ] The note is still there after the page is reloaded.

## Notes

- The seed already has a staff user per permission.
- Use the existing orders test data; the customer is already there.
